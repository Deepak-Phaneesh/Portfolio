# Deepak Phaneesh Naidu Addala — Portfolio Website

An editorial minimalist portfolio website designed in the signature style of **[Dennis Snellenberg](https://dennissnellenberg.com/)**, crafted for **Deepak Phaneesh Naidu Addala** (Full Stack Developer).

---

## ✨ Features & Architecture

1. **Fluid Magnetic Elements**:
   - Custom floating cursor follower that smoothly interpolates and scales over links.
   - Magnetic physics on action buttons that track toward the mouse cursor.
2. **Infinite Marquee Ticker**:
   - Continuous lockstep sliding marquee in the hero section.
3. **Interactive Project Showcase**:
   - Dennis Snellenberg floating cursor preview cards on project hover.
   - Direct live website links (MindLoom, DocuMind, GenAI Tutor) via arrow buttons.
   - Comprehensive technical overview modal with architecture details and GitHub repositories.
4. **Editorial About Section**:
   - Large typography layout with custom narrative and "Let's Connect" magnetic button.
5. **Multilingual Snappy Preloader**:
   - Rapid-fire international & regional greetings ending on name reveal before smooth curved curtain transition.
6. **Dennis Snellenberg Dark Footer**:
   - Signature avatar indicator, copyable email & phone pills, direct LinkedIn button, and live local Indian Standard Time (IST) clock.

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```
